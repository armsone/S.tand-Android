# S.tand iOS → Android 상세 기술 레시피

> 이 문서는 Android판 S.tand의 제품·설계·구현·검증 기준이다. 단순한 화면 복제 문서가 아니라, 현재 iOS 앱의 의도와 상태 전이, 데이터 보존 규칙, 플랫폼 차이를 Android에서 재현하기 위한 실행 명세다.

## 0. 기준과 우선순위

- 작성일: 2026-08-11 KST
- iOS 기준 저장소: `../S.tand` (읽기 전용)
- iOS 기준 커밋: `24f1ec2d94a37189c91d0c31658a0ac7ffa2cc39`
- iOS 기준 버전: `1.0.0 (0.23.3)`
- Android 기준 커밋: `45f864c`
- Android 현재 버전: `0.0.1 (22)`

요구사항이 충돌할 때 우선순위는 다음과 같다.

1. 현재 iOS 소스와 회귀 테스트
2. iOS `PROJECT_RULES.md`
3. 이 문서
4. `docs/IOS_PARITY.md`
5. 과거 디자인 문서와 대화 기록

`docs/DESIGN_RECIPE.md`와 `docs/INTERNET_RADIO_BUTTON_DESIGN_SPEC.md`에는 과거 UI가 일부 남아 있다. 방향 고정, 24시간 표시, 전체 구성 크기 슬라이더, 하단 버튼 순서 편집, 예전 라디오 문구는 Android의 신규 구현 근거로 사용하지 않는다.

## 1. 제품 정의

S.tand는 사용자가 조작법을 외워야 하는 도구가 아니라, 낮에는 책상 위 오브제이고 밤에는 눈에 띄지 않게 곁을 지키는 생활형 앱이다.

### 1.1 경험 모드

| 모드 | 의미 | 화면 | 감지·녹음 | 플래시 |
|---|---|---|---|---|
| 오브제 | 낮의 시계·날씨 데스크 오브제 | 사용자가 정한 앱 밝기 | 중지 | 사용 안 함 |
| 매이트 | 밤의 저광량 돌봄 | 최소 밝기의 시계·날씨 | 뒤척임 감지, 코골이·잠꼬대 후보 녹음 | 평상시 사용 안 함 |
| 화들짝 | 매이트에서 움직임을 감지한 임시 반응 | 잠시 밝아졌다 자연스럽게 복귀 | 기존 감지 문맥 유지 | 방이 어두울 때만 사용 |

모드 표기는 반드시 `오브제 모드`, `매이트 모드`, `화들짝 모드`를 사용한다. `스탠드`, `슬리핑`, `잠자기 모드`, `자동 돌봄` 같은 과거 이름을 신규 UI에 노출하지 않는다.

### 1.2 제품 원칙

- 자동 동작을 기본으로 하되 원터치로 오브제·매이트를 즉시 전환할 수 있어야 한다.
- 앱 내부 밝기만 변경한다. 시스템 화면 밝기를 쓰지 않는다.
- 오브제에서는 마이크, 움직임 감시와 반복 카메라 측정을 하지 않는다.
- 카메라는 매이트 자동 판단에 필요한 경우에만 약 1초 밝기 통계를 얻고 사진·영상을 저장하거나 전송하지 않는다.
- 카메라 설명은 최초 권한 요청 때 한 번만 표시한다. 측정 때마다 배너를 띄우지 않는다.
- 계정, 서버 업로드, 광고, 분석 SDK 없이 기기 안에서 동작한다.
- 의료 진단을 주장하지 않는다. 녹음 분류는 `후보`로 표현한다.

## 2. Android 아키텍처

현재 구조를 유지하되 책임을 아래처럼 고정한다.

| 책임 | Android 구현 위치 | 원칙 |
|---|---|---|
| 영속 설정 | `data/SettingsRepository.kt` | 버전 마이그레이션, 원자적이고 관대한 복원 |
| 제품 상태 | `StandViewModel.kt` | 경험 모드와 센서·오디오·라디오의 유일한 조정자 |
| 순수 정책 | `model/*`, `audio/AudioAnalysis.kt` | Android 프레임워크 의존 없이 JVM 테스트 가능 |
| 홈 | `ui/StandHomeScreen.kt` | 표시와 제스처만 담당, 정책 재구현 금지 |
| 설정 | `ui/SettingsScreen.kt` | 사용자가 이해할 수 있는 기능만 노출 |
| 편집 | `ui/ScreenEditorScreen.kt` | 정보 패널만 편집, 하단 버튼 편집 금지 |
| 녹음 | `recording/*`, `ui/RecordingsScreen.kt` | 승인된 파일만 공개, 세션 단위 표시 |
| 라디오 | `radio/*` | 최대 2개, 전경 재생, 자동 재연결 |
| 센서·권한 | `platform/*` | 구현 세부를 ViewModel 밖으로 격리 |

Compose 화면이 직접 센서나 저장소를 호출하지 않는다. 모든 일회성 액션은 ViewModel 이벤트로 전달하고 상태는 단방향으로 화면에 공급한다.

## 3. 상태 기계

### 3.1 지속 상태

- `modePreference`: `AUTOMATIC`, `OBJECT`, `MATE`
- `environmentMode`: 실제 결정된 `OBJECT` 또는 `MATE`
- `experienceMode`: 표시용 `OBJECT`, `MATE`, `STARTLED`
- `appBrightness`: `0...1`, 앱의 전체 캔버스에 적용
- `isFaceDown`: 휴대폰이 화면을 아래로 향하는지
- `isForeground`: 앱이 전경인지
- `isRadioPlaying`: 라디오가 실제 재생 중인지

### 3.2 앱 시작

1. 방향은 항상 시스템 자동 회전을 따른다.
2. 시간 형식은 항상 12시간제다.
3. 저장 설정과 마이그레이션을 적용한다.
4. `AUTOMATIC`이면 시스템 밝기 값을 읽어 앱 밝기의 초기 참고값으로만 사용한다. 시스템 밝기는 변경하지 않는다.
5. 환경 판단이 끝나기 전에도 시계·날씨 UI는 즉시 표시한다.
6. 오브제면 감시를 시작하지 않는다. 매이트로 결정된 뒤에만 마이크·움직임을 시작한다.

### 3.3 밝기와 원터치

- 오브제/매이트 경계 기본값: 앱 밝기 40%.
- 홈 어디서나 세로 드래그: 앱 밝기 조절.
- 드래그 거리 약 화면 높이의 1/4이 전체 0...100% 범위에 대응한다.
- 오브제에서 한 번 탭: 2초 동안 35%로 이동하여 매이트.
- 매이트에서 한 번 탭: 2초 동안 80%로 이동하여 오브제.
- 100% 도달 직후에는 99%로 표시하고, 끝에서 약 1초 유지하면 `오브제 모드 잠금`이 된다.
- 0%도 같은 방식으로 1초 유지해야 매이트 고정이 된다.
- 잠금이 성립한 뒤 손가락을 떼기 위한 작은 역방향 움직임은 잠금을 취소하지 않는다.
- 자동 상태에서는 외부 밝기 변화에 따라 앱 밝기를 갱신할 수 있지만 수동 드래그 중에는 자동 갱신을 중단한다.

Android 구현에서는 `WindowManager.LayoutParams.screenBrightness`를 변경하지 않는다. 앱 전체 루트에 검은 overlay 또는 색상/alpha 변환을 적용하되, 밝기 피드백·빌드 번호·접근성 포커스가 읽을 수 없게 사라지지 않도록 최소 가독성을 별도 보장한다.

### 3.4 자동 환경 전환

- 조도 센서가 있으면 1차 입력으로 사용한다.
- 센서가 없거나 신뢰도가 낮고 사용자가 카메라를 허용했으면 매이트에서만 카메라 밝기 샘플을 사용한다.
- 어두움/밝음 히스테리시스를 적용해 경계 근처에서 모드가 떨리지 않게 한다.
- 충분한 판단이 되면 1분 이내 전환한다.
- 오브제에서는 반복 카메라 측정을 하지 않는다.
- 매이트에서 밝아진 상태가 유지되면 오브제로 돌아간다.
- 강제 OBJECT/MATE에서는 자동 판단을 적용하지 않는다.

iOS 카메라 기준은 어두움 `0.16`, 밝음 `0.28`이다. Android 센서 lux는 로그 정규화한 뒤 실제 기기 데이터로 캘리브레이션하되, 두 문턱을 합치지 않는다.

### 3.5 화들짝

진입 요인은 매이트 상태에서의 뒤척임 소리 또는 유의미한 기기 움직임이다. 박수·핑거스냅 같은 상대적 급상승도 `다시 밝혀주기`가 켜져 있으면 포함한다.

- 화면: 즉시 밝히고 유지 5초 뒤 30초 동안 자연스럽게 매이트 밝기로 복귀.
- 플래시: `플래시 사용`이 켜져 있고 최근 환경 판단이 어두울 때만 켠다.
- 일반 터치 점등은 플래시를 켜지 않는다.
- 오브제에서는 화들짝을 발생시키지 않는다.
- 휴대폰이 뒤집혀 있으면 화면만 가장 어둡게 처리하고 감지·녹음·세션은 계속한다. 불필요한 화면 렌더링과 애니메이션은 줄인다.

## 4. 홈 화면 명세

### 4.1 레이어

1. 테마 배경
2. 날씨, 시계, 초, 날짜, 배터리, 라디오 정보 패널
3. 상단 상태/브랜드/배터리
4. 하단 고정 버튼(`수면 소리`, `설정`)
5. 흐린 빌드 번호와 앱 밝기
6. 편집·시트·피드백 overlay

상단은 왼쪽 현재 모드, 가운데 S.tand 브랜드, 오른쪽 배터리다. 화면 중앙의 별도 `현재 상태` 텍스트 패널은 표시하지 않는다.

### 4.2 제스처 우선순위

| 제스처 | 동작 |
|---|---|
| 세로 드래그 | 앱 밝기 조절 |
| 단일 탭 | 오브제↔매이트, 2초 애니메이션 |
| 시계 더블 탭 | 테마 순환 |
| 시계 단일 탭 | 글꼴 팔레트 열기/닫기 |
| 화면 롱터치 | 정보 패널 편집 |
| 핀치 | 사용하지 않음. 패널 크기는 편집 핸들로 조절 |

드래그가 시작되면 탭으로 동시에 판정하지 않는다. 자식 패널의 클릭 영역에서도 세로 드래그가 상위 밝기 제스처로 전달되어야 한다. 클릭 가능한 패널은 터치 slop을 넘긴 수직 이동 시 클릭을 취소한다.

### 4.3 시계

- 12시간제 고정.
- 초는 별도 패널이다.
- 초가 시계 패널과 겹치면 배경 없이 숫자만 표시하고, 벗어나면 독립 유리 패널을 사용한다.
- 시계와 숫자에는 같은 플립 중앙 투명 간격을 적용한다.
- 폰트의 실제 glyph 중심과 플립 중심이 맞도록 64pt 기준 수직 보정값을 배율 적용한다.

| 글꼴 | iOS 64pt 보정 |
|---|---:|
| 시스템 둥근체 | -1.5pt |
| Pretendard | 0 |
| Kakao Big Sans | -3pt |
| Nanum Gothic | +1.5pt |
| Tenada | +8pt |
| Black Han Sans | +1.5pt |
| Do Hyeon | +2.5pt |
| Paperlogy | 0 |
| NEXON Lv1 Gothic | +3.5pt |
| Poppins | +0.5pt |

Android 폰트 파일의 ascent/descent가 다르면 위 수치를 맹목적으로 복사하지 말고 동일한 숫자 샘플 `08:49`를 렌더링해 광학 중심을 보정한다. 테스트에는 각 폰트의 계산 보정값을 고정한다.

### 4.4 날씨

- 아이콘, 온도, 상태 3개 정사각 조각.
- 위치명은 온도 위, 체감온도는 아래.
- 위치 아이콘은 Android의 표준 location/navigation glyph를 사용하고 텍스트와 5dp 간격을 둔다.
- 긴 위치명은 아이콘을 고정하고 텍스트만 왕복 marquee 한다.
- 조각이 40% 이상 겹치면 한 패널로 합친다.
- 합친 패널은 더블 탭으로 분리한다.
- 날씨 내용 위에는 별도 투명 가로선을 그리지 않는다.

### 4.5 라디오 패널

- 저장 채널은 최대 2개다.
- 첫째와 둘째 채널이 홈의 첫째와 둘째 패널이다. 번호 선택 UI는 없다.
- 두 패널은 편집에서 40% 이상 겹치면 하나로 합치고, 더블 탭으로 다시 나눈다.
- idle은 채널명과 `대기`, loading은 `연결 중`, reconnecting은 `다시 연결 중`, playing은 `재생`, failed는 `연결 실패`를 상태로 표시한다.
- `탭하여 재생`, `탭하여 취소`, `탭하여 정지`, `감지·녹음 중지` 같은 명령형 보조문구는 화면에 표시하지 않는다. 접근성 hint로만 제공한다.
- 패널 전체가 재생/취소/정지 버튼이며 최소 터치 영역은 48dp다.

## 5. 화면 편집

- 화면 롱터치는 정보 패널만 편집한다.
- 하단 설정 버튼은 더 이상 순서를 변경하지 않는다.
- 이동 범위는 제한하지 않는다. 화면 경계나 다른 패널과 겹쳐도 허용한다.
- 크기는 30...200%만 제한한다.
- 좌상단 크기 핸들을 드래그하되 패널 중심을 유지하며 확대·축소한다.
- 가로·세로 중심선 근처 5%에 오면 패널 중심이 선에 자석처럼 붙는다.
- 시계 위치와 크기도 편집할 수 있다.
- 세로·가로 레이아웃은 독립 저장한다.
- 상단은 `초기화 / 세로(가로) 화면 편집 / 저장`.
- 초기화는 해당 방향의 최신 기본 레이아웃만 draft에 적용하고 저장 전에는 영속 설정을 바꾸지 않는다.

최신 iOS 기본값은 부록 A에 기록한다.

## 6. 설정 화면

설정은 검은 Form이 아니라 현재 테마 배경 위의 밝은 유리 카드 Scroll 화면이다. 테마 선택 색상표 자체에는 그레이스케일 필터를 적용하지 않는다.

순서와 내용:

1. Hero: 앱 아이콘, `S.tand`, `낮에는 오브제\n밤에는 매이트`, 현재 모드 pill. pill은 홈 원터치와 동일.
2. 인터넷 라디오: 같은 카드 안에서 채널 목록, 재생, 추가/수정/삭제. 연필을 누르면 행 바로 아래 editor 표시. 최대 2개.
3. 화면과 시계: 4개 테마 색상표, `시계를 더블 터치하면 테마가 바뀝니다.`, 시계 글꼴. 방향/시간제/전체 크기/화면 배치/버튼 배치 설정은 없음.
4. 권한 설정: 플래시, 카메라, 마이크, 위치를 스위치형 행으로 표시.
5. 잠꼬대와 코골이: `매이트 모드에서만 작동합니다`, 실시간 감지 상태, 다시 밝혀주기, 후보 저장, 수면 소리 열기.
6. 정보: 개인정보, 폰트 저작권, 빌드 정보, 추천 설정 복원.

삭제할 과거 카드/설정:

- 바로 제어
- 화면 방향
- 시간 형식
- 전체 구성 크기
- 화면 배치/버튼 배치 진입
- 조명 밝기·실루엣 밝기·점등 유지·감광 시간을 사용자가 직접 조정하는 고급 UI
- 조도 기준과 마이크 dB 숫자 슬라이더
- 날씨와 기기 카드
- 자동 기능 끄기/감지 종료처럼 범위가 모호한 버튼

권한 스위치를 끄면 해당 기능만 중지한다. Android 권한 자체를 시스템에서 철회할 수는 없으므로 끄기 상태와 OS grant 상태를 구분해 표시한다. 거부 후 다시 요청할 수 없으면 앱 설정 화면으로 안내한다.

|---|---|---|---|
| 오렌지 | `#FF9E47` | `#F2450F` | warm orange |

| 미드나이트 | deep blue | navy black | blue |

유리 패널 기준:

- 일반 top fill: white 9.5%
- 일반 bottom fill: white 5.2%
- 일반 border: white 8%

- 매이트 bottom fill: white 0.8%

## 8. 잠꼬대·코골이 감지

### 8.1 작동 조건

- 전경 + 매이트 + 마이크 사용 켬 + 라디오 미재생 + 배터리 보호 비활성.
- 오브제에서는 AudioRecord를 정지한다.
- 라디오 재생 중에는 감지와 녹음을 일시 중지하고 별도 반복 알림은 띄우지 않는다.

### 8.2 적응형 소리 기준

- 시작 후 60초 동안 주변 RMS 분포를 학습한다.
- 조용한 방에서는 더 민감하고, 음악·선풍기처럼 일정한 배경이 있으면 그 평균보다 유의미하게 올라간 순간에 반응한다.
- 단순한 절대 dB 슬라이더는 사용자에게 노출하지 않는다.
- noise floor는 짧은 버킷의 35 percentile로 추정하고 급격한 transient가 floor를 끌어올리지 못하게 한다.
- 유효 소리 기준은 조용한 방에서 약 -58dB까지 낮아질 수 있고, 시끄러운 방에서는 약 -24dB까지 올라갈 수 있다.

### 8.3 분류

분류 종류: `SNORE`, `SLEEP_TALK`, `MOVEMENT`, `OTHER`.

- 저장: snore confidence >= 0.58, sleepTalk confidence >= 0.60.
- 점등만: movement confidence >= 0.55.
- other는 저장하지 않는다.

잠꼬대 후보 gate:

- duration `0.70...30.0s`
- crest `<=18dB`
- zero crossing ratio `0.025...0.24`
- low-frequency ratio `0.18...0.72`
- active RMS range `>=3.5dB`
- score = `0.35 duration + 0.25 zcr + 0.25 vocalBand + 0.15 nonImpulse`
- score `>=0.60`

TV/라디오 음성과 잠꼬대를 완전히 구별할 수 없음을 UI와 테스트 가정에 명시한다.

### 8.4 파일 승인

- AAC-LC M4A, 약 48kbps.
- pre-roll 0.8초, post-roll 1.4초.
- 90초마다 segment rollover.
- 미분류 파일은 공개 녹음 폴더가 아닌 숨은 staging에 쓴다.
- 이벤트가 승인된 뒤 post-roll 종료 시 atomic move하고 repository에 알린다.
- 중지, 권한 철회, interruption, route 변경, writer 오류 때 승인 전 segment를 전부 삭제한다.
- 승인 뒤 이어진 movement/other는 기존 승인을 취소하지 않는다.
- 앱 시작 때 stale staging을 정리한다.

## 9. 수면 소리 화면

- 기본은 세션별 가로 타임라인 카드만 보이고 녹음 목록은 접힌다.
- 세션은 실제 매이트 진입~이탈로 기록한다.
- 매이트 이탈 후 30분 이내 재진입은 같은 잠자리로 이어 붙인다.
- 과거 파일은 모드 정보가 없으므로 녹음 간 90분 기준으로만 추정하고 `시간 추정`을 표시한다.
- 타임라인에는 녹음 marker와 화들짝 구간을 더 얇은 선으로 함께 표시한다.
- 펼치면 체크, 재생, 진행바, 공유, 삭제를 제공한다.
- `오늘 소리 한데 묶기`는 오늘 원본을 시간순으로 합치고 사이에 0.5초 무음을 둔다.
- 선택 합본 제목은 첫 원본의 시간이다.
- 합본은 별도 묶음에 두고 기본적으로 원본을 보존한다.
- 병합 중에는 원본 삭제·전체 삭제·선택 변경을 막는다.
- accessibility 글꼴에서는 카드와 dock이 세로/2행으로 재배치된다.

## 10. 인터넷 라디오

- HTTPS URL, host 필수, credential 포함 URL 금지.
- 이름과 URL trim 및 길이 제한.
- 최대 2채널, 로컬 저장.
- 앱 전경에서만 재생. 백그라운드 진입 시 정지.
- Android AudioFocus를 요청하고 영구 loss에는 정지, transient loss에는 일시정지 후 재개 여부를 정책으로 결정한다.
- 연결 끊김은 지수 backoff 자동 재연결: 예 `1, 2, 4, 8, 15초`, 최대 시도 후 failed. 사용자의 명시적 정지는 재연결하지 않는다.
- 다른 채널을 누르면 현재 채널을 정지한 뒤 새 채널을 연결한다.
- 재생/연결 중 마이크 감지·녹음은 중지하며, 정지 후 매이트이면 자동 복구한다.
- 공유 URL 수신은 Android Sharesheet를 사용한다. 웹 페이지를 스크래핑해 스트림을 추출하지 않는다.

## 11. 날씨·위치

- 대략적 위치만으로 현재 날씨를 조회한다.
- 네트워크 실패 시 마지막 성공값과 갱신 시각을 유지하고 UI를 비우지 않는다.
- 위치명은 역지오코딩 결과의 중복 행정구역을 제거해 구성한다.
- 위치 권한이 없으면 시계는 항상 정상 표시하고 날씨만 권한 상태를 표시한다.
- API/플랫폼 차이는 `WeatherService` 내부에서 흡수한다.

## 12. 배터리·화면·수명주기

- 배터리 20% 이하이며 충전 중이 아니면 감지·녹음·플래시를 중지하고 경고한다.
- 충전되거나 20%를 넘으면 자동 복구 여부를 명시적으로 테스트한다.
- 앱 전경 동안 화면 자동 잠금은 방지한다.
- 앱 종료/배경에서는 keep-awake, 센서, 카메라, 마이크, 라디오를 정리한다.
- 번인 방지를 위해 정보 묶음을 매우 천천히 몇 px 이동시키되 편집 위치는 바꾸지 않는다.
- face-down에서는 화면 렌더 밝기를 최저로 하고 비싼 애니메이션을 줄이되 돌봄 기능은 유지한다.

## 13. 잠금화면 위젯

- Android lock-screen 위젯 지원은 런처/OS별로 제한된다. 지원되는 호스트에는 1칸 바로 열기 위젯을 제공한다.
- 앱 아이콘의 형태를 유지한 원형 단색 glyph를 사용한다.
- iOS accessory widget의 vibrant 강제 렌더링을 픽셀 단위로 복제하려 하지 않는다.
- 홈 위젯도 동일 glyph와 `S.tand 바로 열기` 의미를 사용한다.

## 14. 데이터와 마이그레이션

### 14.1 저장 원칙

- enum은 화면 문자열이 아닌 안정 raw value로 저장한다.
- 목록 decode는 unknown 제거, 중복 첫 항목 유지, 누락 기본 보충.
- 설정 일부가 손상되어도 전체 설정을 초기화하지 않는다.
- 녹음 manifest는 임시 파일 작성 후 atomic replace.

### 14.2 최신 경험 마이그레이션

Android에 `currentExperienceDefaults.v1` 같은 1회 marker를 둔다. 0.23.3 대응 업데이트에서 한 번만:

- 기본 세로·가로 레이아웃 적용
- 전체 시계 scale `1.0059052830861586`
- 방향 자동, 12시간제
- 하단 버튼은 녹음과 설정만
- 라디오 채널은 앞의 2개만 보존
- 모드 경계 40%, hold 5초, torch 기본 켬

사용자가 업데이트 뒤 바꾼 값은 다음 실행에서 다시 덮어쓰지 않는다. 녹음 파일과 수면 세션은 절대 초기화하지 않는다.

## 17. 검증 기준

각 묶음은 다음을 만족해야 완료다.

- 순수 정책 JVM 테스트
- 저장 schema 구버전/unknown/duplicate/missing 복원 테스트
- `./gradlew testDebugUnitTest`
- `./gradlew assembleDebug`
- `./gradlew lintDebug`
- UI 변경은 허가된 기기/에뮬레이터에서 세로·가로·600dp 이상, 큰 글자, 권한 거부를 확인하되 사용자가 허용하지 않은 세션에서는 실행하지 않는다.
- 마이크·카메라·플래시·센서·AudioFocus는 최종적으로 실기기 검증이 필요하다.

회귀 필수 시나리오:

1. 오브제에서 마이크/카메라/플래시가 작동하지 않는다.
2. 매이트 진입 후 감지와 세션이 한 번만 시작된다.
3. 움직임에 화들짝, 어두운 경우에만 플래시, 이후 복귀.
4. 라디오 재생 중 감지 중지, 정지 후 매이트 감지 복구.
5. 앱 밝기 드래그가 시스템 밝기를 바꾸지 않는다.
6. 짧은 drag가 탭을 함께 발생시키지 않는다.
7. 30분 이내 매이트 재진입은 같은 세션, 초과는 새 세션.
8. unapproved staging은 목록과 재시작 뒤에 보이지 않는다.
9. 기존 녹음은 앱 설정 마이그레이션 뒤에도 남는다.

## 부록 B. 완료 정의

Android판이 iOS와 같다는 말은 색과 위치만 비슷하다는 뜻이 아니다. 아래가 모두 같아야 한다.

- 같은 사용자 행동이 같은 상태 전이를 만든다.
- 권한이 없거나 센서가 실패해도 시계가 계속 보인다.
- 저장·녹음·병합에서 원본과 메타데이터를 잃지 않는다.
- 오브제는 조용하고, 매이트는 눈에 띄지 않으며, 화들짝은 잠깐만 반응한다.
- 사용자가 숫자 임계값을 이해하지 않아도 앱을 사용할 수 있다.
- Android 플랫폼 차이는 숨기지 않고 안전한 대체 동작과 검증 상태를 문서화한다.
