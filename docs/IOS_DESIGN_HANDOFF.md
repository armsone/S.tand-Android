## 기준 소스

- GitHub `armsone/S.tand` main 최신 커밋: `24f1ec2d94a37189c91d0c31658a0ac7ffa2cc39`

- 라디오 세부 규격: iOS `docs/INTERNET_RADIO_BUTTON_DESIGN_SPEC.md`

- Android 작업 폴더에 문서가 없으면 GitHub `armsone/S.tand` main의 위 파일을 읽기 전용 기준으로 사용한다.

## 핵심 제품 상태

- `오브제 모드`: 밝은 환경의 데스크 시계·날씨 오브제. 수면 소리 감시, 자동 녹음과 플래시는 사용하지 않는다.
- `매이트 모드`: 어두운 환경의 최소 밝기 시계·날씨. 뒤척임을 감지하고 코골이·잠꼬대 후보만 녹음한다.
- `화들짝 모드`: 매이트 모드에서 움직임에 화면과 보조 플래시가 잠깐 반응한 뒤 자연스럽게 복귀한다.
- Android에서도 위 상태명과 의미를 그대로 유지한다.

## 핵심 시각·편집 기준

- 오렌지 배경 그라데이션: RGB `(255, 158, 71)` → `(242, 69, 15)`.
- 그레이 테마도 같은 구조를 유지한다.
- 패널은 흰색 기반 저투명 유리 표면, 얇은 테두리와 플립 중앙 간격을 사용한다.
- 시계, 날씨, 날짜, 상태, 배터리와 라디오 패널은 하나의 디자인 언어를 공유한다.
- 날씨 조각은 40% 이상 겹치면 결합하며 결합 후 하나의 패널처럼 보여야 한다.
- 화면 중앙 자석 범위는 5%, 패널 크기 범위는 30~200%이다.
- 화면 롱터치의 정보 패널 편집과 설정 타일 롱터치의 설정 순서 편집을 분리한다.
- 시계 글꼴별 수직 보정값과 정확한 치수는 `DESIGN_RECIPE.md`를 그대로 참조한다.

## iOS 0.23.3과 Android 대응 원칙

- iOS는 Safari 공유 확장에서 사용자가 합법적인 HTTPS 스트림 URL을 앱으로 가져온다.
- Android는 Android Sharesheet/Intent 수신으로 대응한다.
- 라디오는 사용자 제공 HTTPS URL만 사용하고 포그라운드에서 재생한다.
- 라디오는 최대 두 채널이며 두 패널은 화면 편집에서 이동·크기 조절·40% 결합할 수 있어야 한다.
- 라디오 재생과 마이크 기반 소리 감지·수면 녹음은 상호 배제한다.
- 홈 하단은 수면 소리와 설정만 둔다.
- 방향은 자동, 시간 표시는 12시간제로 고정한다.
- 앱 내부 밝기만 조절하며 시스템 밝기를 변경하지 않는다.

## 현재 차이

Android 기준 커밋 `45f864c`는 iOS 0.17.0 수준의 설정과 단일 라디오 모델을 포함한다.
방향·24시간제·전체 크기·하단 버튼 편집을 제거하고, 최신 밝기 상태 기계와 두 채널
라디오, 독립 초 패널, 최신 기본 배치를 순서대로 반영해야 한다.
