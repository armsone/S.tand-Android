# S.tand iOS ↔ Android 동등성 기준

## 고정 기준

- iOS 읽기 전용 저장소: 형제 저장소 `../S.tand`
- 기준 브랜치/커밋: `main` / `24f1ec2d94a37189c91d0c31658a0ac7ffa2cc39`
- 기준 확인일: 2026-08-11 (KST)
- 우선순위: iOS `PROJECT_RULES.md` → 현재 Swift 코드·테스트 → README·PRODUCT 문서
- Android 작업 저장소: 이 저장소 루트

상세 규격은 [`IOS_TO_ANDROID_TECHNICAL_RECIPE.md`](IOS_TO_ANDROID_TECHNICAL_RECIPE.md)를 따른다.
아래의 기존 완료 표에는 0.17.0에서 검증한 역사적 항목이 포함되어 있으므로, 최신 기준과 충돌하면
`최신 차이 요약`과 상세 기술 레시피가 우선한다.

## 기능 사전

| 화면 명칭 | 목적 | 주요 선택지·동작 |
|---|---|---|
| 오브제 모드 | 밝은 환경에서 시계·날씨 오브제로 사용 | 화면을 밝게 유지하고 마이크·녹음·움직임 감시·플래시를 모두 끈다. |
| 매이트 모드 | 어두운 환경에서 잠자리를 조용히 살핌 | 최소 밝기 시계·날씨, 움직임 감지, 코골이·잠꼬대 후보 녹음. |
| 화들짝 모드 | 매이트에서 뒤척임이나 기기 움직임에 잠깐 반응 | 화면과 설정에 따른 보조 플래시를 켠 뒤 자연스럽게 매이트로 돌아간다. |
| 자동 | 주변 밝기를 확인해 오브제·매이트를 전환 | 어두워질 때 20초, 밝아질 때 35초 확인한다. |
| 오브제 유지 | 자동 밝기 판단을 무시하고 오브제를 유지 | 수면 감시와 플래시는 중지한다. |
| 매이트 유지 | 자동 밝기 판단을 무시하고 매이트를 유지 | 감지 권한이 있는 범위에서 수면 감시를 계속한다. |
| 자동 녹음·돌봄 | 앱이 전면에 있는 동안 모드 전환과 필요한 감지를 수행 | 2칸 폭 하단 버튼에서 시작·종료한다. 가로 레일은 현재 마이크 레벨과 주변 소리를 학습해 산출한 자동 기준을 함께 보여 주며, 사용자가 임계값을 직접 조절하지 않는다. |
| 수면 소리 | 저장된 코골이·잠꼬대 후보를 확인 | 재생·탐색·공유·선택·병합·삭제. 목록 화면을 보는 동안 마이크 감시는 쉰다. |
| 화면 편집 | 실제 홈 화면을 보며 방향별 시계·날짜·날씨·상태·배터리 배치를 조절 | 현재 램프 배경과 실제 패널 위에서 이동·30~200% 크기·자석 정렬. 저장 전에는 초안으로 유지하고 취소하면 버린다. |
| 편집 중 시계 글꼴 | 시계 숫자의 결과 모양을 보며 글꼴을 선택 | 시계 패널 한 번 누르기로 실제 `12 : 34` 플립 카드 10종 목록을 열고 다시 눌러 닫는다. 두 번 누르기는 12/24시간제만 전환한다. |
| 플립 패널 표면 | 조명 배경 위 패널을 같은 재질로 표시 | 시계·날씨·배터리·하단 기능 버튼에 따뜻한 저투명 흰색 세로 그라데이션과 약한 흰색 테두리를 공통 적용한다. 시계 카드와 숫자만 같은 중앙 투명 간격을 쓰며 날씨 내용은 자르지 않는다. |
| 날씨 패널 편집 | 날씨 구성 요소를 분리하거나 다시 하나로 결합 | 결합 패널 두 번 누르기로 분리하고, 실제 화면 배율을 반영한 두 패널 교차 면적이 작은 쪽의 40% 이상이면 드래그 종료 때 단일 패널로 결합한다. |
| 인터넷 라디오 패널 | 사용자 HTTPS 스트림을 전경에서 재생 | 설정 화면과 분리된 홈 패널이며 방향별 이동·크기 저장을 지원한다. 재생 중 마이크 감지·녹음을 중지하고 백그라운드에서 종료한다. |
| 플래시 연동 | 매이트의 화면 점등에 후면 플래시를 보조로 사용 | 켬: 일반·움직임 100%, 끔: 일반 0%·움직임 10%. |

## 의도적인 플랫폼 차이

- Android 자동 밝기 판단은 `TYPE_LIGHT` 조도 센서를 우선한다. 센서가 없고 사용자가 카메라 밝기 보조를 켠 경우에만 Camera2의 저해상도 YUV 밝기 중앙값을 사용하며, 해당 프레임은 저장하거나 전송하지 않는다.
- 조도 센서가 없고 카메라 보조를 끈 Android 기기는 시스템 화면 밝기를 대체 입력으로 관찰한다. 이는 주변 조도를 직접 재는 값이 아니므로 실기기별 전환 감도 확인이 필요하다.
- Android도 승인된 새 녹음과 병합 결과를 48kbps AAC/M4A로 저장한다. 후보 판별 중에는 pre-roll·90초 rollover를 무손실로 다루기 위해 앱 비공개 임시 PCM WAV를 사용하며, 코덱 실패 시 사용자 녹음을 잃지 않도록 WAV를 보존한다.
- 기존 Android 설치에 이미 들어간 PCM WAV 샘플은 계속 읽고, 새 설치는 중복 PCM 자산 없이 iOS와 같은 M4A 샘플을 그대로 사용한다.
- Android 600dp 이상 화면에서는 OS 정책상 방향 고정이 무시될 수 있으므로 방향 선택과 별개로 적응형 화면을 제공한다.
- Android 잠금화면 위젯은 OS·런처·OEM 지원이 일정하지 않아 홈 화면 빠른 실행 위젯을 기본 후속 범위로 둔다.

## 검증 상태

- 현재 검증 후보는 Android versionName `0.0.1`, versionCode `22`, 사용자용 빌드 표기 `0.0.22`이다.
- 로컬 `assembleDebug`·`lintDebug`, JVM 단위 테스트 114개가 통과했다. 계측 테스트 3개는 화면 코드 변경 전 0.0.18에서 통과했으며 이번 묶음에서는 반복하지 않았다.
- 전용 AVD와 사용자 지정 SM-T500에서 세로·가로, 오렌지·그레이스케일, 글꼴 10종, 실화면 패널 편집, 버튼 순서 저장, 상하 밝기·좌우 유지 시간 제스처를 확인했다.
- SM-T500과 SM-F968N에 데이터를 유지해 versionCode 22 APK를 설치하고 두 기기에서 Activity의 정상 시작을 확인했다. SM-T500은 Wi-Fi ADB로 검증했다.
- SM-T500에서 M4A 재생·공유창·병합·삭제, 카메라 밝기 보조, 대략적 위치, 백그라운드 센서·녹음·카메라 해제를 확인했다. 이 기기에는 플래시 하드웨어가 없어 실제 점등은 플래시 탑재 기기 검증으로 남긴다.
