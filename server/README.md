# 보이소 인터넷 중계 서버

이 서버는 QR v2 공간 키에서 파생된 익명 채널 안에서 암호화된 사건 프레임만 실시간 전달한다.
공간 키, 원음, 녹음, 사건 본문은 서버로 평문 전송하지 않는다. 서버가 확인할 수 있는 값은
익명 채널, 임의 기기 ID, 연결 시각, 암호문 크기다.

## 실행

Node.js 22 이상에서 `npm install` 후 `npm start`를 실행한다. 외부 공개 시 TLS를 종료하는
리버스 프록시 뒤에 두고 앱 빌드에 `-PBOYISO_RELAY_URL=wss://호스트/v1/relay`를 지정한다.

현재 구현은 온라인 WebSocket 기기 사이의 실시간 중계만 제공한다. APNs·FCM 푸시는 각
플랫폼의 서명 키와 프로젝트 설정이 제공된 뒤 별도 제공자 모듈로 연결해야 한다. 인증정보는
저장소나 QR에 넣지 않는다.

운영 전에는 다중 인스턴스용 공유 pub/sub, 연결 제한, 관측 지표, 개인정보 고지, 장애 대응과
TLS 인증서 자동 갱신을 구성해야 한다.
