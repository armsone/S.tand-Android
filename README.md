# S.tand Android

S.tand iOS 앱을 Android에 맞게 옮기는 Kotlin·Jetpack Compose 프로젝트입니다. 밝은 환경에서는 플립시계와 날씨를 보여 주는 `오브제 모드`, 어두운 환경에서는 움직임을 살피고 코골이·잠꼬대 후보만 기기 안에 보관하는 `매이트 모드`, 움직임에 잠깐 반응하는 `화들짝 모드`를 제공합니다.

## 현재 기준

- Android 앱 버전: `0.0.1`
- 사용자용 빌드 표기: `0.0.26`
- Android `versionCode`: `26`
- applicationId: `com.armsone.stand`
- 최소 SDK: 26
- 대상/컴파일 SDK: 37
- UI: 단일 Activity + Jetpack Compose
- iOS 읽기 전용 기준: 형제 저장소 `../S.tand`, commit `5b7c16ba65ec8217ef461c381c763633776b46f6`

전체 기능 차이와 검증 상태는 [iOS 동등성 문서](docs/IOS_PARITY.md)를 확인하세요. 권한·저장·외부
전송 근거는 [Android 개인정보·Data Safety 문서](docs/ANDROID_DATA_SAFETY.md)에 기록합니다.
개발·검증 규칙은 [PROJECT_RULES.md](PROJECT_RULES.md)가 최우선 기준입니다.

## 빌드 환경

- Android Studio 2026.1 이상 권장
- 저장소에 포함된 Gradle wrapper 9.5.0
- Android Gradle Plugin 9.3.0
- Android Studio 내장 JDK 또는 Java 17 이상
- Android SDK Platform 37

개인 SDK 경로는 추적하지 않는 `local.properties`에 둡니다.

```properties
sdk.dir=/Users/사용자명/Library/Android/sdk
```

기기 없이 로컬에서 확인할 수 있는 명령은 다음과 같습니다.

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew lintDebug
```

## 구현 구조

- `model`: 설정과 오브제·매이트·화들짝 순수 정책
- `audio`: PCM 레벨·박수·코골이·잠꼬대·움직임 판별과 `AudioRecord` 캡처
- `recording`: 내부 PCM 후보 승인·AAC/M4A 확정·90초 조각·목록·병합·30분 수면 세션
- `platform`: 조도·카메라 밝기 보조·가속도·자이로·페이스다운·배터리·플래시 어댑터
- `weather`: 대략적 위치와 Open-Meteo 현재 날씨
- `ui`: 방향별 플립시계 홈·실제 홈 위 화면 편집, 설정, 녹음 재생·선택·병합·공유·삭제 화면
- `widget`: 앱 빠른 실행 홈 화면 위젯

## 0.0.24 라디오 브라우저·라디오 패널·화면 편집 기준

- 화면 편집은 별도 모형 화면이 아니라 현재 램프 배경과 실제 홈 패널을 그대로 보여 주며, 방향별 배치·크기와 하단 버튼 순서를 편집합니다. 저장 전 변경은 초안으로 유지하고 취소하면 버립니다.
- 편집 중 시계 패널을 한 번 누르면 글꼴 선택 목록이 열리고 다시 한 번 누르면 닫힙니다. 두 번 누르기는 목록 토글과 분리해 12/24시간제만 전환합니다.
- 시스템 둥근체와 번들 글꼴 9종은 이름 대신 실제 `12 : 34` 플립 카드로 미리 보여 줍니다. 글꼴별 수직 보정값을 크기에 비례해 적용하고, 카드와 숫자의 투명 가로 간격을 카드 중앙에 함께 맞춥니다.
- 결합된 날씨 패널은 두 번 누르면 구성 요소별로 분리됩니다. 분리 패널을 끌어 놓을 때 실제 화면 배율을 반영한 교차 면적이 작은 패널의 40% 이상이면 하나의 패널로 다시 합칩니다.
- 시계·날씨·배터리·하단 기능 버튼은 따뜻한 저투명 흰색 세로 그라데이션과 매우 약한 흰색 테두리를 공통으로 사용합니다. 날씨 글자와 아이콘은 플립 간격으로 자르지 않습니다.
- 인터넷 라디오는 설정 버튼 안이 아니라 홈의 독립 패널입니다. 화면 편집에서 방향별로 이동·30~200% 크기 조절이 가능하고, 패널을 눌러 HTTPS 스트림을 설정하거나 재생·중지합니다. 재생 중에는 수면 소리 감지와 녹음을 중지합니다.

## 현재 검증 상태

하단 버튼은 플래시, 밝기 기준, 자동 녹음, 녹음 목록, 설정의 5개로 정리했습니다. 자동 녹음은 일반 버튼 2칸 폭이며 실시간 마이크 레벨과 감지 기준을 한 레일에 표시합니다. 레일을 좌우로 밀면 감지 기준(-55~-18 dB)을 바꾸고, 짧게 탭하면 자동 돌봄을 시작하거나 끝냅니다. 기존 저장값에 화면 방향·AiShot 순서가 남아 있어도 안전하게 제외합니다.

버튼이 숨겨진 동안에는 iOS처럼 하단 안내 문구와 그 아래 80dp 영역을 누르면 하단 버튼이 열립니다. 이 영역의 버튼·레일 입력은 전체 화면 밝기·점등 유지 제스처와 분리됩니다. 설정의 모든 카드는 같은 좌우 폭을 사용합니다.

`0.0.24` 후보는 iOS와 같은 HTTPS 전용 앱 내부 라디오 브라우저를 추가했습니다. 기본 즐겨찾기, 주소·검색, 뒤로가기·새로고침을 제공하고 다운로드·파일 업로드·웹 권한은 차단합니다. `0.0.22`에서 상단 브랜드 아이콘과 화면 편집 기준을 정리했고, `0.0.21`에서 독립 라디오 패널과 로컬 HTTPS 스트림 설정을 추가했습니다.

## 개인정보와 플랫폼 범위

- 계정, 광고 SDK, 분석 SDK, 자체 서버가 없습니다.
- 마이크 녹음은 앱 내부 `files/recordings`에만 저장하고 legacy 및 Android 12+ 클라우드 백업·기기 이전에서 제외합니다.
- 녹음은 사용자가 공유를 선택할 때만 FileProvider URI로 다른 앱에 전달합니다.
- 날씨 새로고침 시 대략적 좌표가 Open-Meteo에 전달됩니다.
- 마이크·위치·카메라 권한을 거부해도 시계와 수동 화면 조명은 계속 사용할 수 있어야 합니다.
- 거부한 권한은 설정 화면에서 항목별로 다시 요청하거나 시스템 앱 권한 설정에서 직접 허용할 수 있습니다.
- 백그라운드 녹음과 마이크 foreground service는 현재 범위에 포함하지 않습니다.

## 기기 검증 주의

다른 Android 변환 작업이 같은 연결 기기를 사용 중이면 이 프로젝트에서 `adb`, 설치, 실행, 계측 테스트, 권한·화면 설정 변경을 하지 않습니다. 해당 작업이 끝난 뒤 전용 serial 또는 전용 AVD를 명시해 검증합니다.
